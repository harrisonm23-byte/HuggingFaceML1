# Experiment F: peer lines to write (template)

**What this is.** A blank script for the third party in Experiment F. At each of the six push requests, UBS speaks
exactly as in B. Then one or two other banks' agents ("peers") join the chat and say they're in. You write the peer
lines. I'll wire them in exactly as written, the same way the frozen framing file is read.

**Rules for step 1 (the pure crowd)**
- Peers only **signal that they're in**: no loss or gain framing, no "you", no reasons, no pressure words. The only
  thing that changes from B is the number of other parties going along.
- **Same meaning for Peer 1 and Peer 2** at each request, in different words, so a second peer adds a voice and not a
  new argument.
- **Trading days only.** Peers say nothing in the 34 chat-only days.
- The peer's bank name is up to you. Use counterparties from the record, or neutral labels such as "Bank C".

**Cells:** B's *neutral* and *loss + you* UBS lines, each with +1 and +2 peers. That makes 4 new versions × 10 careers.
"UBS alone" is B itself.

**Timing (my proposal, a mechanics choice):** the peer lines arrive in the same chat, right after UBS's push line and
before the agent's first decision. That way the agent sees the crowd when it chooses.
